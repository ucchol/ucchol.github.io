Research

I study how limitations in an attacker’s decision-making affect cybersecurity, and how these behaviors can inform defensive strategies. My work combines behavioral experiments, cognitive models, and game-theoretic analysis.

Research interestsPublicationsResearch code

Research interests

Cyber deception and security games

I study how a defender should allocate deceptive resources when attackers respond imperfectly. This includes quantal Stackelberg models, uncertainty about attacker behavior, and coordinated deception across cyber and physical systems.

Attacker cognition and choice overload

In human-subject experiments, I investigate how choice-set size and attribute information affect target selection. I fit discrete choice and cognitive process models to understand the decisions people make under information load.

Malware and malicious-domain detection

I also work on detecting malicious domains and malware, focusing on evaluation against families excluded from training and on identifying out-of-distribution threats.

Research code

Quantal Stackelberg cyber deception

How should a defender plan when its model of an attacker is wrong? This notebook compares quantal Stackelberg equilibrium (QSE) with a perfectly rational best-response baseline, using a cyber–physical deception testbed built from real vulnerabilities. It includes the solver, attacker-model comparisons, and sensitivity experiments.

Code & notebook · Related paper

Choice overload in cyber defense

This project examines how the number of options and the information attached to them affect decisions. The repository contains experimental data and analysis notebooks for laptop selection, file exfiltration, and port-scanning tasks, including analyses of decision regret.

Code & data · Related paper

Network defense with reinforcement learning

A defender allocates limited hardening and incident-response resources while an attacker probes a network. This project compares learned policies with optimization and heuristic baselines, asking whether behavior learned on smaller networks transfers to larger ones.

Code & results · Notebook

NXDOMAIN Sentinel

A domain-name classifier evaluated on malware families withheld from training. A separate novelty gate measures distance from known families in the model’s representation. Together, the experiments examine two questions: does a domain look malicious, and does it look unfamiliar?
